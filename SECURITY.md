# Security policy

KnownPath is under active phased development. Security fixes target the current `main` branch and
the latest published installer package.

Please report vulnerabilities privately through GitHub's **Security > Report a vulnerability** flow
for this repository. Do not include credentials, private knowledge, tenant identifiers, or a working
exploit in a public issue. See [`docs/SECURITY_OPERATIONS.md`](docs/SECURITY_OPERATIONS.md) for
operator response and credential-rotation guidance.
